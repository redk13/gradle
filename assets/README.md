# Source media

The repository stores source links, creator names, verified licence terms and use notes in `config/baarle.json` and `SOURCES_AND_LICENSES.md`.

The original photographs, enclave map and Natural Earth boundaries are fetched at run time into temporary Google Colab storage. Music and most SFX use direct Mixkit CDN files; the mechanical stamp is a CC0 Freesound recording. The previous Pixabay storefront-page scrape (which returned HTTP 403 in Colab) has been removed. Audio is not stored in GitHub, cropped or rendered there. BiRefNet-HR inference is run only in Colab.
