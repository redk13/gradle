# Source media

The repository stores source links, creator names, verified licence terms and use notes in `config/baarle.json` and `SOURCES_AND_LICENSES.md`.

The original photographs, enclave map and Natural Earth boundaries are fetched at run time into temporary Google Colab storage. All music and sound effects use direct Mixkit CDN files; no Pixabay or Freesound storefront pages are scraped. Audio is not stored in GitHub, synthesized, cropped or rendered there. BiRefNet-HR inference is run only in Colab.
