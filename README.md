# Baarle Map Short — production pack

A map-led vertical geography/history short built from the supplied British Empire reference. The Colab notebook is restricted to `redk13/gradle` and performs the one-time voice/cutout/render pipeline in Google Colab only.

See `SOURCES_AND_LICENSES.md` for factual references and asset licences, and `colab/BAARLE_SINGLE_CELL.ipynb` for the single-cell production entry point.
